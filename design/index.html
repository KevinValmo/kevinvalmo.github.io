Design System 🖋️

A sepia typographic system inspired by letterpress newspapers and ink-on-parchment printing. Every visual decision is rooted in warmth, legibility, and the quiet authority of the printed page. No framework. No build tool. No external dependency — pure HTML and CSS, served as-is.

Color Palette

All colours are defined as CSS custom properties on :root and must always be referenced by token name — never hardcoded. The palette is structured in two layers: the raw named colours (--color-*) and the semantic aliases (--bg, --text, --accent, …) consumed by components.

Type Scale

Sizes follow a classical editorial progression expressed in rem units. The base size is set slightly above 1rem for improved screen readability of the serif face.

Headings

All headings use --font-serif in bold weight. The h1 carries a 2 px bottom border in --border. The h2 generates a short accent underline via a CSS ::after pseudo-element — a quiet nod to the column rules of a broadsheet newspaper. h4 drops to italic normal weight for use as a pull subtitle.

Divider

The <hr> element renders as an ornamental typographic rule. Its default border is suppressed and replaced by a ::before glyph composed of em-dashes and a four-pointed star (U+2726), echoing the decorative rules found in 19th-century newspaper columns.

Spacing

All layout spacing uses the --space-* scale. Never use arbitrary pixel or raw rem values. Note: --space-7, --space-9, and --space-11 are intentionally absent — the scale jumps at specific points to maintain a coherent rhythm.

Design Principles

The following rules govern every visual decision on the site:

  1. No external dependencies. Every CSS value is defined locally. No CDN fonts, no icon libraries, no framework stylesheets.
  2. Token-first. Raw colour hex values must never appear in CSS rules or HTML attributes — use --color-* or their semantic aliases.
  3. Single stylesheet. All styles live in public/style.css. Additional stylesheets and inline <style> blocks are forbidden.
  4. Sepia warmth. The palette stays within the warm brown-amber-cream family. Cool greys and pure black are avoided.
  5. Typographic hierarchy. Heading sizes, weights, and decorative rules create clear editorial hierarchy without relying on colour alone.
  6. Spacing discipline. Only --space-* tokens may be used for margins, paddings, and gaps. Arbitrary values break the rhythm.

This design system is intentionally minimal. The constraint is the point: no build tool, no preprocessor, no dependency — just tokens, types, and craft.
